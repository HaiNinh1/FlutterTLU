# Personal Portfolio – Nguyễn Hải Ninh (Flutter)

Ứng dụng giới thiệu bản thân viết bằng Flutter, chạy trên Web, Android, Windows.

## Cách chạy

```bash
flutter pub get
flutter run -d chrome   # chạy trên trình duyệt
flutter test            # test giao diện ở cỡ điện thoại và máy tính
flutter build web       # đóng gói web -> build/web
flutter build apk       # đóng gói Android
```

Kịch bản thuyết trình giải thích code: xem file [THUYET_TRINH.md](THUYET_TRINH.md).

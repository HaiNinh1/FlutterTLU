# Ứng dụng Profile Cá nhân (Android - Java + XML)

## Cách chạy
1. Mở **Android Studio** → `File > Open` → chọn thư mục `bai4` → chờ Gradle Sync.
2. Chọn máy ảo **Pixel_7_API_34** → bấm **Run ▶**.

## Sửa thông tin của bạn
| Muốn sửa | File |
|---|---|
| Họ tên, lớp, tiểu sử | `app/src/main/res/values/strings.xml` |
| Các đường link | `app/src/main/java/com/example/profileapp/MainActivity.java` |
| Ảnh đại diện | Thay file `app/src/main/res/drawable/avatar.png` (giữ nguyên tên file) |

Giải thích chi tiết code: xem `GIAI_THICH_CODE.md`.
